# Rishu Khatak — Editorial Portfolio

A personal portfolio website for **Rishu Khatak** (MBA Human Resources Candidate @ UPES & B.Sc. (Hons.) Computer Science Graduate @ University of Delhi).

---

## ✦ Concept & Design Philosophy

**"People. Potential. Perspective."**  
*Bringing structured analytical thinking into people-focused leadership.*

The website is crafted with an editorial design language:
- **Palette**: Warm ivory parchment (`#F6F2EA`), deep ink navy (`#17212B`), muted slate (`#66717A`), refined teal (`#477B76`), and warm terracotta (`#C9826F`).
- **Typography**: Editorial serif (`Playfair Display`, `Cormorant Garamond`) paired with geometric sans-serif (`Plus Jakarta Sans`, `Inter`) and mono (`JetBrains Mono`).
- **Botanical Storytelling**: Custom scroll-triggered Sakura (Cherry Blossom) SVG motifs symbolizing personal growth, transitions, and learning.
- **In-App Resume Experience**: In-app PDF resume preview modal with zoom controls, download PDF (`Resume-Rishu.pdf`), and download DOCX (`Resume-Rishu.docx`).

---

## ✦ Core Sections

1. **Header & Navigation**: Sticky header with monogram, live availability pill (`Open to HR Opportunities`), and quick resume viewer.
2. **Hero**: First-person positioning statement, credential badges, and editorial headline.
3. **Statistics Bar**: Fact-based metrics (2028 MBA target, 2025 B.Sc. Hons, NCC Captain, 2 Core Disciplines).
4. **01 — Profile & Perspective**: First-person narrative on transitioning from Computer Science to Human Resources.
5. **02 — HR Approach**: 4 pillars (*People*, *Leadership*, *Organization*, *Analytics*).
6. **Chapter 02 — Growth & Evolution**: Interactive journey timeline with scroll reveals and botanical flourishes.
7. **04 — Leadership Experience**: Feature spotlight on NCC Captain experience.
8. **05 — Projects & Explorations**:
   - *Operational*: Event Management System (Planning → Coordination → Execution → Reflection).
   - *Analytical*: Advancement in Software Bugs Severity Management (Detect → Classify → Prioritize → Resolve).
9. **06 — Competency Matrix**: Filterable skills categorized across People & Management, Productivity, Technical & Analytics, and Languages.
10. **07 — Academic Pedigree**: Chronological degrees and coursework.
11. **08 — Beyond the Resume**: National Level Hockey, District Level Football, Hackathon, and personal pursuits.
12. **09 — Initiate Conversation**: One-click copy for email and phone with instant toast, direct resume downloads, and an inquiry form.
13. **Footer**: Dark obsidian footer with navigation index and smooth back-to-top control.

## ✦ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Animations**: Framer Motion
- **Icons**: Lucide React

## ✦ Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Development

```bash
# Clone the repository
git clone <repo-url>
cd <repo-folder>

# Install dependencies
npm install

# Start development server
npm start
# or
npm run dev

# Build for production
npm run build
```
