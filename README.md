# Rishu Khatak — Editorial Portfolio

A personal portfolio website for **Rishu Khatak** (MBA Candidate @ UPES & B.Sc. (Hons.) Computer Science Graduate @ University of Delhi), positioned for **Marketing, Brand Strategy & Analytics** opportunities.

---

## ✦ Concept & Design Philosophy

**"Where Brand, Campaigns & Data Analytics Meet."**  
*Bringing structured analytical thinking, campaign promotions, and disciplined execution into modern marketing.*

The website is crafted with an editorial design language:
- **Palette**: Warm ivory parchment (`#F6F2EA`), deep ink navy (`#17212B`), muted slate (`#66717A`), refined teal (`#477B76`), and warm terracotta (`#C9826F`).
- **Typography**: Editorial serif (`Playfair Display`, `Cormorant Garamond`) paired with geometric sans-serif (`Plus Jakarta Sans`, `Inter`) and mono (`JetBrains Mono`).
- **Smooth Interaction & Scroll Effects**: Interactive progress bar, framer-motion section reveals, interactive project category filters, and subtle organic line motifs.
- **In-App Resume Experience**: In-app PDF resume preview modal with zoom controls, download PDF (`Resume-Rishu.pdf`), and download DOCX (`Resume-Rishu.docx`).

---

## ✦ Core Sections

1. **Header & Navigation**: Sticky header with monogram, live availability pill (`Open to Marketing Opportunities`), and quick resume viewer.
2. **Hero**: First-person positioning statement, credential badges, and editorial headline.
3. **Statistics Bar**: Fact-based metrics (2028 Target MBA, 2025 B.Sc. Hons, NCC Captain, 2 Core Disciplines).
4. **01 — Profile & Perspective**: First-person narrative on bridging Computer Science, data analysis, and campaign promotion.
5. **02 — Marketing Approach**: 4 pillars (*Audience & Engagement*, *Campaign Execution & Logistics*, *Marketing Analytics & Insights*, *Leadership & Adaptability*).
6. **03 — Projects Showcase**: Interactive multi-tab filter showcasing:
   - *Campaign Operations*: Event Management System & Campaign Promotion (Promotions, participant engagement, registration funnel, venue logistics).
   - *Digital Experience*: Personal Portfolio & Digital Brand Experience (AI-assisted web architecture, responsive design, modern UI).
   - *Analytics & Research*: Advancement in Software Bugs Severity Management (AI/ML classification, severity prioritization, structured analysis).
7. **04 — Growth & Evolution**: Interactive journey timeline with scroll reveals and milestone markers.
8. **05 — Leadership Experience**: Feature spotlight on NCC Captain experience (discipline, teamwork, decision-making).
9. **06 — Competency Matrix**: Filterable skills categorized across Marketing & Campaigns, Analytics & Data, Productivity & Creative Tools, and Languages.
10. **07 — Academic Pedigree**: Chronological degrees and coursework.
11. **08 — Beyond the Resume**: National Level Hockey, District Level Football, Hackathon, and personal pursuits.
12. **09 — Initiate Conversation**: One-click copy for email and phone with instant toast, direct resume downloads, and an inquiry form.
13. **Footer**: Dark obsidian footer with navigation index and smooth back-to-top control.

## ✦ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Animations**: Framer Motion
- **Icons**: Lucide React

## ✦ Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Development

```bash
# Clone the repository
git clone <repo-url>
cd <repo-folder>

# Install dependencies
npm install

# Start development server
npm start
# or
npm run dev

# Build for production
npm run build
```
